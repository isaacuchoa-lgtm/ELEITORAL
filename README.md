# Vote For Julio

Crie a interface e o código para um site de sistema eleitoral moderno, intuitivo e responsivo com dois candidatos fictícios: Julio 1 e Julio 2.

### Requisitos de Estrutura e Funcionalidades:

* **Cabeçalho:** Título principal "Sistema de Votação", status visual de "Votação Aberta" e contador de votos totais.

* **Cards dos Candidatos:**

  * **Candidato 1 - Julio 1 (Número 10):** Card com foto de perfil vinda de um banco de imagens gratuito, breve biografia e 3 propostas fictícias.

  * **Candidato 2 - Julio 2 (Número 20):** Card com foto de perfil vinda de um banco de imagens gratuito, breve biografia e 3 propostas fictícias.

* **Fluxo de Votação:**

  * Botão "Votar" individual em cada card.

  * Modal/Pop-up de confirmação de voto com as opções "Confirmar Voto" e "Corrigir".

  * Mensagem de sucesso após a confirmação.

* **Painel de Resultados (Dashboard):**

  * Seção gráfica ou barra de progresso mostrando a porcentagem e total de votos em tempo real para Julio 1 e Julio 2.

  * Botão de "Reiniciar Votação" para testes.

### Estilo e Imagens Stock:

* Interface desenvolvida com HTML5, Tailwind CSS e JavaScript puro.

* As fotos dos candidatos devem carregar URLs diretas de imagens de stock gratuitas e sem direitos autorais.
